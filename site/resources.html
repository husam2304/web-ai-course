الدورة 5: فن الـ Prompt

3. قالب الـ Prompt الثابت

الدورمين بدك الـ AI يكون؟«أنت مطور مواقع بتساعد مبتدئ»
السياقالفكرة والجمهور«مخبز عائلي صغير في عمّان، زبائنه العائلات بالحي»
المطلوبشو بدك بالضبط، بجملة واضحة«اعملي الصفحة الرئيسية فيها عنوان وصور 3 منتجات وزر اطلب الآن»
الشكلالألوان، الخط، الترتيب«ألوان دافئة، والزر واضح فوق»
القيودالحدود اللي لازم يلتزم فيها«بالعربي، مناسب للجوال، بدون تسجيل دخول»
النتيجةشو بدك يرجعلك«كود كامل» أو «تعديل محدد بس» أو «شرح بجملتين»

3 تقنيات أعلى مستوى: «اسألني قبل ما تجاوب» · أعطِه مثال · قسّم المهمة خطوة خطوة. وأول جواب مسودة: اطلب تعديلات لحد ما يناسبك.

Prompt

قبل ما تقترح أي شي، اسألنا 5 أسئلة، سؤال سؤال، عشان تفهم مشروعنا.
بعد ما نجاوب، لخّصلنا:
1) الفئة المستهدفة وليش بتزور الموقع

1. خطة الفريق

  1. انسخ الـ prompt والصقه بالـ AI، ومعه تقرير الجمهور والأهداف تبع امبارح.
  2. جاوب على أسئلته، وعدّل بإيدك اللي مش عاجبك. القالب تحت إذا بدكم تعبّوه بإيدكم.
  3. ورّوا المدرب الخطة قبل ما تبلشوا الـ Wireframes.
  4. انسخ الخطة بزر النسخ تبع الـ AI (مش بالتظليل) والصقها بخانة «خطة الفريق» بصفحة التسليم، عشان يضل تنسيقها. واحد من الفريق بكفي.
Prompt خطة الفريق 
أنا بفريق ببني موقع بسيط (Frontend فقط، بدون Backend) بدورة للمبتدئين.
هاي فكرتنا وتقرير الجمهور والأهداف اللي طلع معنا امبارح:
[الصق التقرير هون، أو اكتب الفكرة بجملتين إذا ما عندكم تقرير]

عبّيلي «خطة الفريق» بالعربي، بنقاط قصيرة، وبهالترتيب:
1. الفكرة بجملة وحدة.
2. الجمهور (فئة وحدة محددة، مش «كل الناس») و3 أهداف للموقع.
3. الإجراء الرئيسي: الزر الأهم بالموقع.
4. الصفحات: من 3 لـ 6 صفحات، ولكل صفحة أقسامها بالترتيب.
5. ضروري ولاحقاً: شو بيدخل بالنسخة الأولى، وشو بيتأجل.
6. ميزتين تفاعليتين على الأقل بـ JavaScript. أي ميزة بدها Backend (تسجيل دخول، حجز، دفع، حفظ تقييمات) اكتب جنبها «واجهة عرض فقط».
7. خريطة الموقع كشجرة نصية.
8. الإحساس العام للتصميم: 3 كلمات بتوصف الأسلوب (مثلاً: هادئ، عصري، دافئ) واقتراح ألوان.

قبل ما تكتب: إذا في شي ناقص أو مش واضح، اسألني 3 أسئلة بالكثير.

الدورة 6: Google Stitch

3. Prompt الـ Stitch

الصقه بـ ChatGPT أو Claude وعبّي اللي بين [ ]، وخذ الـ prompt الإنجليزي اللي بيطلع وحطه بـ Stitch مع صور الـ wireframes.

Prompt لـ ChatGPT 
أنا بدي أصمم موقع باستخدام Google Stitch.
اكتبلي prompt بالإنجليزي لـ Stitch بناءً على هاي المعلومات:
- الفكرة والجمهور والإجراء الرئيسي: [من خطة الفريق]
- الصفحات وأقسام كل صفحة بالترتيب: [من الـ wireframes]
- الميزات التفاعلية ومكانها: [الميزتين أو أكثر]
- دليل التصميم: الألوان [HEX]، الخطوط [أسماء الخطوط]، شكل الزر [الوصف]
- قواعد الوصول: تباين ناجح، كل حقل إله عنوان ظاهر، نص الأزرار واضح
الموقع لازم يكون كل نصوصه بالعربي، واتجاهه من اليمين لليسار (RTL)، ومتوافق مع الجوال، وكل الصفحات بنفس الـ Header والـ Footer.
اطلب تصميم كل صفحة كشاشة Desktop منفصلة.
خلي الـ prompt واضح ومرتب بنقاط.
طلبات تحسين جاهزة داخل Stitch (طلب واحد بكل مرة) 
Make the CTA button bigger and use the accent color.
Use the same header and footer on all pages.
All text must be in Arabic, right-to-left.
Show the mobile version of the home page with a hamburger menu.

الختام

4. التسليم

  • اختار فريقك واسمك من القائمة.
  • شغل الفريق (الخطة كنص، صور الـ wireframes، تصميم Stitch): أي حد بالفريق بيرفعه، مرة وحدة بكفي.
  • كل واحد بيجاوب سؤال الفهم بكلماته وباسمه.
  • عملت شغل زيادة لحالك أو موقع جانبي؟ في خانة «شغل إضافي».
  • لا تحط ملفات عشوائية، الملفات مش إجبارية.

Prompt 1: الهيكل

Prompt 
أنا مبتدئ ببني موقع [فكرة الموقع] بـ HTML و CSS و JavaScript عادي، بدون Tailwind وبدون أي مكتبة.
اللغة: [عربي RTL / إنجليزي LTR]. الصفحات: [index.html, menu.html, ...].
مرفق ملف التصميم DESIGN.md (أو صورة الرئيسية): خد منه الألوان والخطوط بس.
بدي:
1. هيكل المجلدات: css/style.css و js/data.js و js/main.js و images/.
2. style.css فيه :root بـ 6 لـ 8 متغيرات بس (خلفية 60%، أساسي 30%، مميز 10%، لون النص، الخط، الزوايا)، وclasses مشتركة: .container .btn .card .cards، و header و footer و media query للجوال مع hamburger.
3. index.html فيها الهيكل الكامل (header مع nav لكل الصفحات وزر hamburger، main فاضي، footer)، و data.js قبل main.js آخر الـ body.
4. data.js فيه مصفوفة اسمها items فيها عنصرين مثال بالحقول: [id, name, category, price, image ...].
5. main.js فيه كود الـ hamburger بس.
اشرحلي بالعربي بسطر شو وظيفة كل ملف.

لكل صفحة، مع إرفاق صورة الشاشة

Prompt 2: بناء صفحة من الصفر

Prompt 
هاي صورة تصميم صفحة [اسم الصفحة]. ابنيها بـ HTML و CSS عادي، بدون Tailwind.
هاد الـ style.css المشترك عندنا: [الصق style.css]
وهاد الـ header والـ footer: [الصقهم]
الشروط:
- استخدم المتغيرات والـ classes الموجودة، ولا تعدّل style.css.
- أي CSS جديد خاص بالصفحة حطه بملف css/[اسم-الصفحة].css.
- الصور من مجلد images/ بأسماء واضحة، ولكل صورة alt.
- البطاقات المتكررة (منتجات، أدوات، كتب) لا تكتبها بالـ HTML: حط مكانها <div id="list" class="cards"></div> بس.
- بدون JavaScript بهالخطوة.
ابني الصفحة قسم قسم، وبعد كل قسم اشرح بسطرين بالعربي شو عملت.

لكل ميزة

Prompt 3: ميزة JavaScript خطوة خطوة

Prompt 
بدي أضيف ميزة [وصف الميزة، مثلاً: بحث وفلترة للمنيو حسب الفئة].
البيانات بملف data.js هيك: [الصق عنصرين من المصفوفة]
وهاد الـ HTML تبع الجزء: [الصقه]
اكتب الكود بـ JavaScript عادي، على خطوات، كل خطوة لحالها ومعها شرح بالعربي.
استخدم const/let و forEach و filter و addEventListener، ولا تستخدم مكتبات.
الكود بينضاف لـ main.js المشترك بين كل الصفحات: حطه بـ function باسم واضح، وجوا if بتتأكد إن العنصر موجود.
اعطيني الكود الجديد بس، ولا تعيد كتابة main.js كله.

بعد كل ميزة، وقبل سؤال الفهم

Prompt 5: تصليح خطأ

Prompt 
الميزة [اسمها] مش شغالة. هاد الخطأ من الـ Console: [الصق الخطأ الأحمر كامل]
وهاد الكود: [الصق الجزء]
قلي شو سبب الخطأ بجملة، وبعدين اعطيني السطر المصلّح بس، مش الملف كله.

للفرق اللي بدها تبديل لغة

Prompt 6: موقع بلغتين

Prompt 
موقعي [عربي RTL]. بدي زر بيبدّل للـ [إنجليزي LTR] ويرجع.
الطريقة: كل نص عليه data-i18n="مفتاح"، والنصوص بـ object اسمه texts فيه ar و en، والزر بيغيّر lang و dir على <html>، والاختيار بينحفظ بـ localStorage عشان يضل بكل الصفحات.
الـ CSS لازم يشتغل بالاتجاهين: استخدم margin-inline و padding-inline بدل left و right.
ابدأ بـ 3 نصوص بس كمثال (العنوان، الـ nav، الزر)، واشرحلي كل خطوة.
