# ورقة تصليح: the sun

الهدف اليوم: موقع «وازن» فيه على الأقل صفحتين شغالين ومربوطين ببعض: **إعداد الميزانية** و**لوحة التحكم**. بالملفات اللي وصلت ما في بناء من اليوم 3.

## خطوة 1: الهيكل

اعملوا مجلد `wazen` وجواه `css` و `js` و `images`:

```text
wazen/
├── index.html       ← البداية (بعدين)
├── setup.html       ← إعداد الميزانية (اليوم)
├── dashboard.html   ← لوحة التحكم (اليوم)
├── reports.html, settings.html   ← بعدين
├── css/
│   ├── style.css    ← المشترك
│   ├── setup.css, dashboard.css
├── js/
│   ├── setup.js, dashboard.js
└── images/
```

**البيانات عندكم مش بـ `data.js`:** المستخدم هو اللي بيدخلها، فبتنحفظ بـ `localStorage`. المهم إن كل الصفحات تستعمل **نفس المفتاح ونفس الشكل**:

```js
// المفتاح: wazen
{ income: 500, categories: [ { name: "أكل", cap: 150, spent: 40 } ] }
```

## خطوة 2: صفحة الإعداد مع الملف المشترك

انسخوا هاد الـ prompt، وارفقوا معه صورة شاشة «إعداد الميزانية الشهرية في دقيقة» من Stitch، وملف `DESIGN.md`:

```text
احنا فريق the sun، بنبني موقع «وازن» لإدارة الميزانية الشخصية بـ HTML و CSS و JavaScript عادي، بدون Tailwind وبدون أي مكتبة. الموقع عربي RTL.
مرفق صورة صفحة «إعداد الميزانية» من التصميم، وملف DESIGN.md: خد منه الألوان والخطوط بس.
بدي 4 ملفات:
1. css/style.css: المشترك بين كل الصفحات: :root فيه 6 لـ 8 ألوان بس من DESIGN.md، و body، و header فيه اسم الموقع وقائمة روابط (index.html و setup.html و dashboard.html و reports.html و settings.html)، و footer، وأزرار .btn، وبطاقات .card، و @media للجوال.
2. setup.html: الصفحة زي الصورة. بتربط css/style.css وبعده css/setup.css، وبآخر الـ body بتربط js/setup.js.
3. css/setup.css: اللي خاص بهاي الصفحة بس.
4. js/setup.js: المستخدم بيدخل دخله الشهري وسقف لكل بند، وبيقدر يضيف بند أو يحذفه. بكبسة «حفظ» البيانات بتنحفظ بـ localStorage تحت مفتاح اسمه wazen بهالشكل بالضبط: { income: رقم, categories: [ { name: نص, cap: رقم, spent: 0 } ] }، وبعدين بتنتقل لـ dashboard.html. لما الصفحة تفتح، بتعبّي القيم المحفوظة إذا موجودة.
اعطيني كل ملف كامل بدون اختصار بـ code block لحاله وفوقه اسمه. وبعد كل ملف اشرح بسطرين بالعربي شو بيعمل.
```

**جرّبوا:** افتحوا `setup.html`، عبّوا الدخل وبندين، واحفظوا. بعدين F12 ← Application ← Local Storage: لازم تشوفوا المفتاح `wazen`.

## خطوة 3: لوحة التحكم

انسخوا هاد الـ prompt، وارفقوا صورة شاشة «توزيع أسقف البنود» من Stitch:

```text
هاي صورة صفحة «لوحة التحكم» بموقعنا «وازن». تحت ملف style.css المشترك، والـ header والـ footer من صفحة setup.html.
بدي dashboard.html و css/dashboard.css و js/dashboard.js بـ HTML و CSS و JavaScript عادي، بدون Tailwind:
- الصفحة زي الصورة، بنفس الـ header والـ footer بالضبط، وبتستخدم المتغيرات والـ classes اللي بـ style.css. بتربط css/style.css وبعده css/dashboard.css.
- dashboard.js بيقرأ البيانات من localStorage (المفتاح wazen، والشكل: { income, categories: [ { name, cap, spent } ] }) وبيرسم بـ loop بطاقة لكل بند: الاسم، والسقف، والمصروف، وشريط تقدم.
- لون الشريط: أخضر تحت 80% من السقف، برتقالي من 80%، أحمر إذا تجاوز السقف.
- فورم صغير «أضف مصروف»: بتختار البند وبتكتب المبلغ، فبيزيد spent وبينحفظ وبترجع البطاقات تنرسم.
- إذا ما في بيانات محفوظة، رسالة «ابدأ من صفحة الإعداد» مع رابط لـ setup.html.
اعطيني كل ملف كامل بدون اختصار بـ code block لحاله وفوقه اسمه. وبالآخر اشرحلي بالعربي بـ 3 أسطر كيف الـ loop بيرسم بطاقة.

style.css:
(الصق هون)

الـ header والـ footer:
(الصق هون)
```

## خطوة 5: الصفحات الباقية (إذا ضل وقت)

نفس prompt خطوة 3، بس بتغيّروا الصورة والمطلوب:

- `index.html`: صفحة ترحيب بزر «ابدأ» بيودي على `setup.html`.
- `reports.html`: صورة «التقرير المالي الشهري»، وزر طباعة بـ `window.print()`.
- `settings.html`: صورة «إعدادات التطبيق»، وزر «امسح كل البيانات».
