# ورقة تصليح: آفاق

الهدف اليوم: نحوّل صفحتكم الوحدة لموقع من 4 صفحات. الصفحة عندكم فيها كل اشي أصلاً: الاختبار، والمكتبة مرسومة من مصفوفة `books`، واقتراح كتاب بينحفظ. بس الـ CSS والـ JS مكتوبين جوا الملف، وملف `mine.css` مش مربوط (نسخة قديمة).

## خطوة 1: نسخة احتياطية

اعملوا zip لمجلد `reders.1` زي ما هو، وارفعوه على «ملفات فريقي».

## خطوة 2: الهيكل الجديد

```text
afaq/
├── index.html      ← البداية (hero)
├── quiz.html       ← اختبار الذائقة والنتيجة
├── library.html    ← المكتبة والفلاتر
├── suggest.html    ← اقترح كتاب
├── css/
│   └── style.css
├── js/
│   ├── main.js      ← المشترك (إذا في)
│   ├── data.js      ← مصفوفة الكتب
│   ├── quiz.js, library.js, suggest.js
└── images/
```

## خطوة 3: قسّموا الصفحة مع الـ AI

انسخوا هاد الـ prompt، والصقوا تحته محتوى `indx.html` كامل:

```text
هاد ملف indx.html لموقعنا «آفاق». كله بصفحة وحدة، والـ CSS جوا <style> والـ JavaScript جوا <script>.
بدي تقسمه لموقع من 4 صفحات، بنفس الشكل والوظائف بالضبط:
- index.html: الـ hero (section class="hero")
- quiz.html: اختبار الذائقة والنتيجة (section id="quiz")
- library.html: المكتبة والفلاتر (section id="library")
- suggest.html: اقترح كتاب (section id="suggest")
كل صفحة فيها نفس الـ header ونفس الـ footer. بالـ header قائمة روابط للصفحات الأربع. إذا ما في header، اعمل واحد بسيط بنفس الألوان.

الملفات:
- css/style.css: كل الـ CSS اللي جوا <style> زي ما هو، وزيد عليه بس شكل الـ header والـ footer إذا عملتهم جديد.
- js/data.js: مصفوفة books بس، زي ما هي.
- js/quiz.js و js/library.js و js/suggest.js: كل صفحة الكود اللي بيخصها من الـ <script>، بدون تغيير بالمنطق.
- أي function بتستعملها أكثر من صفحة (مثل escapeHTML)، حطها بـ js/main.js مرة وحدة.

الربط:
- كل صفحة بتربط css/style.css بالـ head.
- بآخر الـ body، بهالترتيب: js/main.js (إذا موجود)، بعدين js/data.js (بس للصفحات اللي بتستعمل الكتب)، بعدين ملف الصفحة.
- إذا في زر بيودي على قسم صار بصفحة ثانية (مثلاً href="#library")، خليه يودي على الصفحة (library.html).
- إذا نتيجة الاختبار بتستعمل function من المكتبة (مثل showCategory)، احكيلي كيف حليتها.

ابعتلي ملفين بكل رد، كل ملف بـ code block لحاله وفوقه اسمه ومساره، كامل بدون اختصار. أنا بكتب «كمّل» عشان تبعت اللي بعدهم.
بالآخر اعطيني قائمة بكل الملفات اللي عملتها.

indx.html:
```

احفظوا كل ملف بمكانه حسب الهيكل فوق، واحذفوا `mine.css` و `indx.html` القديم من المجلد الجديد (بيضلوا بالنسخة الاحتياطية).

## خطوة 4: تأكدوا من الأسلاك

افتحوا كل صفحة بالمحرر، وتأكدوا إن هاي الأسطر موجودة:

| الصفحة | بالـ head | آخر الـ body |
| --- | --- | --- |
| `index.html` | `css/style.css` | `js/main.js` (إذا موجود) |
| `quiz.html` | `css/style.css` | `js/main.js` ← `js/data.js` ← `js/quiz.js` |
| `library.html` | `css/style.css` | `js/main.js` ← `js/data.js` ← `js/library.js` |
| `suggest.html` | `css/style.css` | `js/main.js` ← `js/suggest.js` |

- [ ] الشكل زي ما كان بالصفحة الوحدة.

## خطوة 6: تحسين

**افهموا الـ loop اللي عندكم:** المكتبة مرسومة من `data.js` أصلاً، وهاد بالضبط اللي بنشرحه اليوم. اسألوا الـ AI:

```text
هاد ملف library.js من موقعنا. اشرحلي function اسمها renderBooks سطر سطر بالعربي البسيط، كأني أول مرة بشوف JavaScript: وين بتمسك العنصر، وكيف الـ loop بيمرق على الكتب، وشو بتغيّر بالصفحة. وبالآخر اسألني سؤال واحد عشان أتأكد إني فهمت.

library.js:
(الصق هون)
```

**صفحة خامسة (إذا ضل وقت):** خطتكم فيها «تواصل وعن آفاق». ابنوها بنفس الـ header والـ footer، وضيفوها للقائمة بكل الصفحات.

## خطوة 7: الأزرار والروابط اللي ما بتودي على إشي

إذا كبستوا زر أو رابط ورجعكم لنفس المكان، يعني إنه `href="#"` أو زر ما إله حدث. افتحوا شات جديد، وارفقوا الصفحة وملف الـ JS تبعها، وانسخوا:

```text
مرفق صفحة index.html و main.js من موقعنا «آفاق». صفحات الموقع: index.html و quiz.html و library.html و suggest.html.
بدي:
1. جدول بكل رابط (a) وكل زر (button) بالصفحة ما بيودي على إشي: href="#" أو href فاضي أو بيودي على قسم مش موجود، أو زر ما إله حدث بالـ JS. لكل واحد: النص المكتوب عليه، ووين لازم يودي من صفحات الموقع. وإذا بده سيرفر (دخول، تسجيل، اشتراك، دفع، تقييم بينحفظ): «واجهة عرض»، يعني بيطلّع رسالة بس.
2. بعد الجدول صلّحهم: الروابط بالـ HTML، والأزرار بـ JS بملف الصفحة، جوا function باسم واضح.
3. لا تغيّر الشكل، ولا أي ميزة شغالة، ولا أي class أو id مستعمل بالـ JS.
إذا تغيّر إشي: اعطيني الملفات اللي تغيّرت بس، كل ملف كامل بدون اختصار بـ code block لحاله وفوقه اسمه. وإذا ما في ولا رابط أو زر ميت: لا تبعت كود، اكتب بس «ما في روابط ميتة بـ index.html».
```

وللصفحات الباقية بنفس الشات:

```text
نفس الشي لـ quiz.html، ومرفق quiz.js.
```

بعد كل صفحة: كبسوا كل زر ورابط فيها، وتأكدوا إن الـ Console نظيف.
