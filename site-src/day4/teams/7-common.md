# مشاكل شائعة وحلها (لأي فريق)

الأمثلة هون لموقع منيو بصفحة تفاصيل `item.html` وبيانات بمصفوفة `items` بملف `data.js`. غيّروا الأسماء لأسماء ملفاتكم، وارفقوا ملفاتكم مع كل prompt.

## صفحة تفاصيل لكل عنصر (`?id=`)

إذا صفحة التفاصيل عندكم دايماً بتعرض نفس العنصر. لازم البيانات تكون بـ `data.js` قبل.

```text
مرفق item.html: صفحة تفاصيل بموقعنا، ومعبّاية لعنصر واحد بس. ومرفق data.js (مصفوفة items) وملف الـ JS اللي بيرسم البطاقات.
بدي الصفحة تشتغل لكل العناصر:
1. إذا الـ objects بـ items ما فيها id، ضيف id رقم من 1 لكل عنصر، وما تغيّر إشي ثاني.
2. ملف js/item.js: بيقرأ الـ id من الرابط (item.html?id=3) بـ URLSearchParams، وبيدوّر على العنصر بـ items، وبيعبّي الصفحة بكل معلوماته.
3. بـ item.html: حط id واضح على كل عنصر بيتعبّى، وخلي الشكل والـ classes زي ما هم.
4. إذا ما في id أو العنصر مش موجود: رسالة «مش موجود» مع رابط للصفحة الرئيسية.
5. زر التفاصيل بكل بطاقة يودي على item.html?id= رقم العنصر.
6. بآخر الـ body بـ item.html: js/data.js بعدين js/item.js.
اعطيني الملفات اللي تغيّرت بس، كل ملف كامل بدون اختصار بـ code block لحاله وفوقه اسمه.
```

## ميزة ما بتشتغل لما نكبس

افتحوا F12 ← Console، واكبسوا الزر، وانسخوا أي سطر أحمر. بعدين ارفقوا الصفحة وملفات الـ JS تبعها و `data.js`:

```text
ميزة بموقعنا مش شغالة: لما نكبس الزر ما بيصير إشي. مرفق الصفحة وملفات الـ JS تبعها و data.js.
وهاد اللي بيطلع بالـ Console لما نكبس:
(الصق الخطأ هون، أو اكتب: ما في خطأ)

بدي:
1. قلي بجملتين ليش ما بتشتغل. مثلاً: الـ addEventListener بيصير قبل ما البطاقات تنرسم، أو ملف الـ JS مش مربوط، أو اسم class أو id غلط، أو البيانات ما بتنتقل من صفحة لصفحة.
2. صلّحها على نفس الطريقة اللي مبنية فيها. وإذا البيانات لازم تنتقل لصفحة ثانية: بالرابط (?id=) أو بـ localStorage.
3. لا تغيّر الشكل ولا أي ميزة ثانية شغالة.
اعطيني الملفات اللي تغيّرت بس، كل ملف كامل بدون اختصار بـ code block لحاله وفوقه اسمه.
```

## الأزرار والروابط اللي ما بتودي على إشي

```text
مرفق صفحة من موقعنا وملف الـ JS تبعها. بدي:
1. جدول بكل رابط (a) وكل زر (button) بالصفحة ما بيودي على إشي: href="#" أو href فاضي أو بيودي على قسم مش موجود، أو زر ما إله حدث بالـ JS. لكل واحد: النص المكتوب عليه، ووين لازم يودي من صفحات الموقع. وإذا بده سيرفر (دخول، تسجيل، دفع، تقييم بينحفظ): «واجهة عرض»، يعني بيطلّع رسالة بس.
2. بعد الجدول صلّحهم: الروابط بالـ HTML، والأزرار بـ JS بملف الصفحة.
3. لا تغيّر الشكل، ولا أي ميزة شغالة، ولا أي class أو id مستعمل بالـ JS.
إذا تغيّر إشي: الملفات اللي تغيّرت بس كاملة. وإذا ما في ولا رابط ميت: لا تبعت كود، اكتب بس «ما في روابط ميتة».
```
