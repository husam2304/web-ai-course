# ورقة تصليح: IT Team

الهدف اليوم: 4 صفحات بموقع واحد (الرئيسية، المأكولات، المشروبات، التواصل). القائمة عندكم صح أصلاً، بس أسماء الملفات عشوائية (`bb.html` و `a.css` و `mail.js`)، والـ JS مش مربوط، وصفحة المأكولات ما إلها JS، والرئيسية مش موجودة. الموقع اللي بـ «الشغل الإضافي» بيضل لحاله، وما بندمجه.

## خطوة 1: نسخة احتياطية

اعملوا zip لمجلد `IT Team` زي ما هو، وارفعوه على «ملفات فريقي».

## خطوة 6: طلّعوا الـ CSS المشترك

> إذا الـ AI وقف بنص الملف، اكتبوا: «كمّل من وين وقفت». وإذا كتب «باقي الكود زي ما هو»، اكتبوا: «اعطيني الملف كامل بدون اختصار».

**6أ. الملف المشترك `style.css`:** افتحوا شات جديد، وارفقوا ملفات الـ CSS (`drinks.css` و `food.css` و `contact.css` و `home.css`)، وانسخوا هاد الـ prompt:

```text
مرفق 4 ملفات CSS من موقعنا (مطعم إيطالي): drinks.css و food.css و contact.css و home.css. كل ملف تبع صفحة، وكل واحد فيه :root خاص فيه بأسماء متغيرات متشابهة وألوان قريبة من بعض.
بهاد الرد بدي ملف style.css بس، وما بدي ملفات الصفحات هلأ.

1. :root واحد بس:
   - وحّد المتغيرات المتشابهة: إذا في متغيرين بيعملوا نفس الشغلة (لون أساسي، خلفية، نص، حدود...) حتى لو الاسم أو درجة اللون مختلفة شوي، خليهم متغير واحد باسم واضح، وقيمته من drinks.css.
   - الهدف 8 لـ 12 متغير بالكثير.
2. القواعد المشتركة كلها بـ style.css، مرة وحدة: * و *::before و *::after و body و a و img و button، و .material-symbols-outlined و .text-primary و .text-tertiary و .container و .main-content و .sep و .copyright، والـ header (.site-header و .header- و .brand- و .main-nav و .nav-link و .phone-pill و .mobile-menu-btn و .lang-btn)، والـ footer (.site-footer و .footer-)، و @media تبعهم.
   - إذا القاعدة مختلفة شوي بين الملفات: خد نسخة drinks.css. الاختلافات البسيطة بتنحذف.
   - كل var() جوا style.css لازم يستعمل الأسماء الجديدة بس.
3. بعد الملف اعطيني جدول «خريطة المتغيرات»: كل متغير قديم من كل ملف ← المتغير الجديد اللي صار مكانه. هاد الجدول رح نستعمله بالخطوات الجاية.

اعطيني style.css كامل بدون اختصار بـ code block واحد، وبعده الجدول.
```

حطوا الناتج بـ `css/style.css`. بعدين بـ `food.html` و `drinks.html` و `contact.html` ضيفوا هاد السطر **قبل** سطر ملف الصفحة (`index.html` بتكون رابطته أصلاً):

```html
<link rel="stylesheet" href="css/style.css">
```

**6ب. ملفات الصفحات، وحدة وحدة (بنفس الشات):** انسخوا هاد الـ prompt لأول ملف:

```text
هلأ drinks.css. اعمله من drinks.css الأصلي اللي بعتتلك إياه، بهالشروط:
- ممنوع يكون فيه :root، ولا * ولا html ولا body ولا a ولا img ولا button ولا scrollbar، ولا أي قاعدة من القواعد المشتركة اللي حطيتها بـ style.css. هدول كلهم بـ style.css وبس، حتى لو القيم هون مختلفة شوي.
- كل var(--اسم-قديم) بدّله بالاسم الجديد حسب «خريطة المتغيرات».
- إذا في لون مكتوب مباشرة (مثل #00e5ff) وهو نفس أو قريب من متغير بالـ :root، بدّله بـ var() تبع المتغير.
- القواعد الخاصة بالصفحة خليها زي ما هي، وما تغيّر غير أسماء المتغيرات.
اعطيني drinks.css كامل بدون اختصار بـ code block واحد. وبالآخر سطر: «فحص: ما في :root ولا body ولا header ولا footer بهاد الملف».
```

وللملفات الباقية بنفس الشات (`food.css`، بعدين `contact.css`، بعدين `home.css`)، غيّروا الاسم بس:

```text
نفس الشي لـ food.css.
```

بعد كل ملف: بدّلوه، وافتحوا الصفحة، وتأكدوا إن شكلها زي قبل (فرق بسيط بدرجة لون عادي). F12 ← Elements ← `<html>` ← Styles: لازم تشوفوا `:root` واحد بس، جاي من `style.css`. إذا اشي خرب، رجّعوا الملف القديم ونادوا حسام.

**6ج. صلّحوا الـ classes بالصفحات (بنفس الشات، صفحة صفحة):** ارفقوا الصفحة وملف الـ JS تبعها إذا موجود (`food.html` و `index.html` لسا ما إلهم JS)، وانسخوا:

```text
هلأ صار عندنا style.css وملف CSS لكل صفحة (اللي بعتتهم فوق). مرفق صفحة drinks.html وملف الـ JS تبعها drinks.js.
بدي تفحص كل class بالـ HTML:
- إذا الـ class موجود بـ style.css أو drinks.css: خليه زي ما هو.
- إذا مش موجود بولا ملف، وفي class موجود بيعمل نفس الشغلة (مثلاً زر أو بطاقة أو عنوان بنفس الشكل): بدّله بالموجود.
- إذا مش موجود وما في إشي مناسب: خليه زي ما هو، وحطه بالقائمة تحت.
- وإذا في style="..." بالـ HTML أو بالـ JS فيه var(--اسم-قديم): بدّل الاسم حسب «خريطة المتغيرات».
ممنوع:
- تغيّر أي class أو id مستعمل بملف الـ JS (querySelector أو getElementById أو classList)، حتى لو مش موجود بالـ CSS، لأنه الـ JS بيعتمد عليه.
- تغيّر النصوص أو الصور أو الروابط أو ترتيب العناصر.
- تعدّل ملفات الـ CSS.
اعطيني:
1. جدول: الـ class القديم ← الجديد، وبأي عنصر.
2. قائمة الـ classes اللي ما لقيتلها بديل.
3. إذا تغيّر إشي: drinks.html كامل بدون اختصار بـ code block واحد. وإذا ما تغيّر ولا إشي: لا تبعت الكود، اكتب بس «ما في تغيير على drinks.html».
```

وللصفحات الباقية بنفس الشات (`food.html`، بعدين `contact.html`، بعدين `index.html`):

```text
نفس الشي لـ food.html (ما إلها ملف JS).
```

إذا الـ AI حكى «ما في تغيير»، الصفحة بتضل زي ما هي. وإذا عطاكم كود: بدّلوا الصفحة، وافتحوها، وجربوا الميزات اللي فيها.

