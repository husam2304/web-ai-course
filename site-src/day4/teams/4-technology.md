# ورقة تصليح: تكنولوجيا (نقطة AI)

الهدف اليوم: الصفحات الأربع (الرئيسية، التصنيفات، المقارنة، عن الموقع) موقع واحد مربوط. المشكلة عندكم بالمسارات: كل صفحة بمجلد، والمسار مكتوب كأنه من برّا (`SH3/css/main3.css` من جوا `SH3` نفسه)، فولا ملف CSS أو JS مربوط. وكمان في أسطر بتدوّر على ملفات مش موجودة أصلاً (`style.css` و `script.js`).

## خطوة 1: نسخة احتياطية

اعملوا zip لمجلد `All folder` زي ما هو، وارفعوه على «ملفات فريقي».

## خطوة 2: الهيكل الجديد

noqta-ai/

## خطوة 4: صلّحوا الأسلاك

كل صفحة فيها سطرين CSS وسطرين JS. واحد منهم بيدوّر على ملف مش موجود: **احذفوه**. والثاني **صلّحوه**:

| الصفحة | احذفوا السطر اللي فيه | بدل | اكتبوا |
| --- | --- | --- | --- |
| `index.html` | `style.css` و `script.js` | `css/main.css` | `css/home.css` |
| `index.html` |  | `JS/main.JS` | `js/home.js` |
| `category.html` | `category.css` و `category.js` | `sh2/css/main2.css` | `css/category.css` |
| `category.html` |  | `sh2/JS/main2.JS` | `js/category.js` |
| `about.html` | `about.css` و `about.js` | `SH3/css/main3.css` | `css/about.css` |
| `about.html` |  | `SH3/JS/M.js` | `js/about.js` |
| `compare.html` | `compare.css` و `compare.js` | `SH4/css/main4.css` | `css/compare.css` |
| `compare.html` |  | `SH4/JS/main4.JS` | `js/compare.js` |

**القائمة (nav):** القائمة الصح بـ `compare.html` (فيها الرئيسية والتصنيفات والمقارنة وعن الموقع). انسخوا الـ `<nav class="main-nav" ...>` كاملة من هناك لحد `</nav>`، والصقوها مكان الـ nav بـ `index.html` و `category.html` و `about.html`.

**جرّبوا هلأ:** افتحوا `index.html` وتنقلوا بين الصفحات الأربع، وجربوا البحث والفلترة بالرئيسية.

## خطوة 5: طلّعوا الـ CSS المشترك

> إذا الـ AI وقف بنص الملف، اكتبوا: «كمّل من وين وقفت». وإذا كتب «باقي الكود زي ما هو»، اكتبوا: «اعطيني الملف كامل بدون اختصار».

**5أ. الملف المشترك `style.css`:** افتحوا شات جديد، وارفقوا ملفات الـ CSS (`home.css` و `category.css` و `compare.css` و `about.css`)، وانسخوا هاد الـ prompt:

```text
مرفق 4 ملفات CSS من موقعنا «نقطة AI»: home.css و category.css و compare.css و about.css. كل ملف تبع صفحة، وكل واحد فيه :root خاص فيه بأسماء متغيرات متشابهة وألوان قريبة من بعض.
بهاد الرد بدي ملف style.css بس، وما بدي ملفات الصفحات هلأ.

1. :root واحد بس:
   - وحّد المتغيرات المتشابهة: إذا في متغيرين بيعملوا نفس الشغلة (لون أساسي، خلفية، نص، حدود...) حتى لو الاسم أو درجة اللون مختلفة شوي، خليهم متغير واحد باسم واضح، وقيمته من home.css.
   - الهدف 8 لـ 12 متغير بالكثير.
2. القواعد المشتركة كلها بـ style.css، مرة وحدة: * و body و a و ::-webkit-scrollbar، و .container و .main-content، والخلفية (.bg-effects و .orb والـ @keyframes تبعها)، والـ header (.site-header و .header- و .logo- و .main-nav و .nav-link)، والـ footer (.site-footer و .footer- و .legal-links)، و @media تبعهم.
   - إذا القاعدة مختلفة شوي بين الملفات: خد نسخة home.css. الاختلافات البسيطة بتنحذف.
   - كل var() جوا style.css لازم يستعمل الأسماء الجديدة بس.
3. بعد الملف اعطيني جدول «خريطة المتغيرات»: كل متغير قديم من كل ملف ← المتغير الجديد اللي صار مكانه. هاد الجدول رح نستعمله بالخطوات الجاية.

اعطيني style.css كامل بدون اختصار بـ code block واحد، وبعده الجدول.
```

حطوا الناتج بـ `css/style.css`. بعدين بالصفحات الأربع ضيفوا هاد السطر **قبل** سطر ملف الصفحة:

```html
<link rel="stylesheet" href="css/style.css">
```

**5ب. ملفات الصفحات، وحدة وحدة (بنفس الشات):** انسخوا هاد الـ prompt لأول ملف:

```text
هلأ home.css. اعمله من home.css الأصلي اللي بعتتلك إياه، بهالشروط:
- ممنوع يكون فيه :root، ولا * ولا html ولا body ولا a ولا img ولا button ولا scrollbar، ولا أي قاعدة من القواعد المشتركة اللي حطيتها بـ style.css. هدول كلهم بـ style.css وبس، حتى لو القيم هون مختلفة شوي.
- كل var(--اسم-قديم) بدّله بالاسم الجديد حسب «خريطة المتغيرات».
- إذا في لون مكتوب مباشرة (مثل #00e5ff) وهو نفس أو قريب من متغير بالـ :root، بدّله بـ var() تبع المتغير.
- القواعد الخاصة بالصفحة خليها زي ما هي، وما تغيّر غير أسماء المتغيرات.
اعطيني home.css كامل بدون اختصار بـ code block واحد. وبالآخر سطر: «فحص: ما في :root ولا body ولا header ولا footer بهاد الملف».
```

وللملفات الباقية بنفس الشات (`category.css`، بعدين `compare.css`، بعدين `about.css`)، غيّروا الاسم بس:

```text
نفس الشي لـ category.css.
```

بعد كل ملف: بدّلوه، وافتحوا الصفحة، وتأكدوا إن شكلها زي قبل (فرق بسيط بدرجة لون عادي). F12 ← Elements ← `<html>` ← Styles: لازم تشوفوا `:root` واحد بس، جاي من `style.css`. إذا اشي خرب، رجّعوا الملف القديم ونادوا حسام.

**5ج. صلّحوا الـ classes بالصفحات (بنفس الشات، صفحة صفحة):** ارفقوا الصفحة وملف الـ JS تبعها، وانسخوا:

```text
هلأ صار عندنا style.css وملف CSS لكل صفحة (اللي بعتتهم فوق). مرفق صفحة index.html وملف الـ JS تبعها home.js.
بدي تفحص كل class بالـ HTML:
- إذا الـ class موجود بـ style.css أو home.css: خليه زي ما هو.
- إذا مش موجود بولا ملف، وفي class موجود بيعمل نفس الشغلة (مثلاً زر أو بطاقة أو عنوان بنفس الشكل): بدّله بالموجود.
- إذا مش موجود وما في إشي مناسب: خليه زي ما هو، وحطه بالقائمة تحت.
- وإذا في style="..." بالـ HTML أو بالـ JS فيه var(--اسم-قديم) أو متغير زي --brand-glow: بدّل الاسم حسب «خريطة المتغيرات».
ممنوع:
- تغيّر أي class أو id مستعمل بملف الـ JS (querySelector أو getElementById أو classList)، حتى لو مش موجود بالـ CSS، لأنه الـ JS بيعتمد عليه.
- تغيّر النصوص أو الصور أو الروابط أو ترتيب العناصر.
- تعدّل ملفات الـ CSS.
اعطيني:
1. جدول: الـ class القديم ← الجديد، وبأي عنصر.
2. قائمة الـ classes اللي ما لقيتلها بديل.
3. إذا تغيّر إشي: index.html كامل بدون اختصار بـ code block واحد. وإذا ما تغيّر ولا إشي: لا تبعت الكود، اكتب بس «ما في تغيير على index.html».
```

وللصفحات الباقية بنفس الشات (`category.html`، بعدين `compare.html`، بعدين `about.html`):

```text
نفس الشي لـ category.html، ومرفق category.js.
```

إذا الـ AI حكى «ما في تغيير»، الصفحة بتضل زي ما هي. وإذا عطاكم كود: بدّلوا الصفحة، وافتحوها، وجربوا الميزات اللي فيها.

**الـ JS:** كل صفحة إلها ميزات مختلفة، فما بنعمل `main.js` اليوم.

## خطوة 8: صفحة الأداة (آخر شي، إذا ضل وقت)

`tool.html` لسا مكتوبة بـ Tailwind، و Tailwind ممنوع. ما تربطوها بالقائمة قبل ما تخلص. انسخوا هاد الـ prompt، وارفقوا صورة شاشة صفحة ChatGPT من Stitch:

```text
هاي صورة تصميم صفحة تفاصيل أداة (ChatGPT) بموقعنا «نقطة AI». ابنيها بـ HTML و CSS عادي، بدون Tailwind وبدون أي مكتبة.
هاد ملف style.css المشترك عندنا (فيه الألوان والـ header والـ footer)، وتحته الـ header والـ footer من صفحة compare.html.
الشروط:
- استخدم نفس الـ header والـ footer بالضبط، ونفس المتغيرات والـ classes اللي بـ style.css.
- أي CSS جديد حطه بملف css/tool.css. الصفحة بتربط css/style.css وبعده css/tool.css.
- الصفحة عربي RTL.
- ابني الصفحة قسم قسم، وبعد كل قسم اشرح بسطر بالعربي شو عملت.
اعطيني tool.html و tool.css كاملين.

style.css:
(الصق هون)

الـ header والـ footer:
(الصق هون)
```

**الصور:** روابط Stitch، نزّلوها على `images/` وغيّروا الـ `src`.
